# Rindhali Thoddoo — guesthouse website

Website for **Rindhali Thoddoo**, a brand-new guesthouse on Thoddoo island, Alif Alif Atoll, Maldives.

- 9 pages: Home, Rooms, Dining, Thoddoo, Gallery, Reviews, Plan Your Trip, Contact, Privacy
- Languages: English, Arabic, Russian, German, French, Italian
- Plain HTML, CSS and JavaScript, so it runs on GitHub Pages with no build step

## Editing
- Contact details (WhatsApp, phone, email, Instagram, Facebook): top of `site.js`
- Translations: `i18n.js` (one line per phrase)
- Photos: `assets/` (add `assets/thoddoo-aerial.jpg` to show the aerial photo on the Thoddoo page)
